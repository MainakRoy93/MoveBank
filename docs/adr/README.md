# Architecture Decision Records

This directory records architecture decisions for the Base Earth platform.

## Numbering

ADRs use a four-digit sequence:

- `0001-record-architecture-decisions.md`
- `0002-frontend-foundation.md`

Once an ADR is accepted, do not rewrite its decision. If the project changes direction, add a new ADR that supersedes the old one.

## Status Values

- `Proposed`: under discussion.
- `Accepted`: current project direction.
- `Superseded`: replaced by a later ADR.

## Template

```md
# ADR NNNN: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

What forces, constraints, and current facts matter?

## Decision

What decision are we making?

## Consequences

What gets easier, harder, or deliberately deferred?
```
